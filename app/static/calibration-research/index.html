What would count as learning?

If adjusted forecasts have lower error than both the unadjusted model and the sportsbook baseline on the same future games, that supports further investigation. A small difference or a range crossing zero is inconclusive.

Rules fixed before collection

  • Capture the first eligible pregame prediction 5–60 minutes before scheduled start. Odds must be no more than 60 minutes old.
  • Only predictions created after experiment activation qualify. Every game gets one immutable record.
  • Source or fitted-parameter changes pause new captures. Saved games can still settle.
  • Changed start times and postponed games are excluded for every forecast.
  • The diagnostic checkpoint is after 60 days, with at least 200 scored games. Smaller samples remain inconclusive. No automatic betting changes.

Results refresh here once per minute; collection runs every five minutes. Existing data collection supplies the odds. No extra paid odds requests are made.
